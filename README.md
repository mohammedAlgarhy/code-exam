# CodeExam - منصة اختبارات البرمجة

## 🚀 التقنيات المستخدمة
- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- GSAP

## 📁 هيكل المشروع

\\\
my-app/
├── app/           # صفحات التطبيق
├── components/    # المكونات المشتركة
├── lib/          # دوال مساعدة
├── hooks/        # Custom Hooks
├── context/      # React Context
├── types/        # تعريفات TypeScript
├── data/         # بيانات مؤقتة
└── public/       # ملفات ثابتة
\\\

## 🛠️ التشغيل

1. تثبيت التبعيات:
\\\ash
npm install
\\\

2. تشغيل المشروع:
\\\ash
npm run dev
\\\

3. فتح المتصفح على:
\\\
